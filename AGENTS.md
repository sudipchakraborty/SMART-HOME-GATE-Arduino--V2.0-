# Project instructions

## Completion notification

- Beep when a requested task is done.

## Progress tracking

- Update the root `progress.md` for every change made in this repository, including code, libraries, configuration, documentation, and project instructions.
- Keep entries chronological, dated, and written in plain language so the user can understand what changed and why.
- List affected files, verification performed and its actual outcome, upload status when relevant, and any remaining work or limitations.
- Record failed checks or blocked work honestly. Distinguish compilation, upload verification, and observed hardware behavior.
- Preserve previous entries. Do not record credentials or other secrets.
- Include the progress update in the same task as the change, before the final response.
